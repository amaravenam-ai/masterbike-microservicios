# Dependencias

Dependencias declaradas en los ocho pom.xml: Spring Boot, Spring Data JPA, Hibernate, Flyway, MySQL Connector/J, Lombok, springdoc, Spring Cloud/OpenFeign y bibliotecas de pruebas. Se resuelven con Maven; no se copian cachés ni JAR en el repositorio. Las licencias de terceros se mantienen separadas del aviso propio.
Los scripts mvnw/mvnw.cmd y metadatos Maven Wrapper son de Apache Maven y conservan su cabecera Apache-2.0 cuando está presente. No se atribuyen como creación propia.

Se registraron 85 bibliotecas de runtime construidas en evidencia/dependencias-runtime.json. Para 84 se leyó la declaración de licencia del POM o su padre; para spring-boot-jarmode-tools se leyó LICENSE/NOTICE dentro del JAR. El inventario no incorpora esos binarios al repositorio. Antes de redistribuir imágenes o JAR hay que conservar y revisar también sus avisos y obligaciones de distribución. El aviso de derechos propios no sustituye ninguna licencia de terceros.
